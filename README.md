# Pong Game

A simple implementation of the classic Pong game using HTML5 Canvas and JavaScript.

## How to Run

1. Open `index.html` in any modern web browser
2. Or use a local server:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`

## How to Play

- **Player 1 (Left Paddle - Green)**: Use `W` (up) and `S` (down) keys
- **Player 2 (Right Paddle - Red)**: Use `Arrow Up` and `Arrow Down` keys
- First player to reach 5 points wins!
- Click "Reset Game" button to start a new game

## Features

- Two-player local multiplayer
- Score tracking
- Ball physics with paddle collision detection
- Responsive paddle controls
- Game over detection
- Reset functionality

## Files

- `index.html` - Main HTML structure
- `pong.js` - Game logic and rendering
- `style.css` - Styling and layout

Enjoy the game!
